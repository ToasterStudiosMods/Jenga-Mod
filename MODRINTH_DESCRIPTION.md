# About
This mod adds the abillity to create a jenga tower that has realisic physics with the /stack command it works 1 - 999 but you can change this with the gamerule. It fully has a dragging abillity to take out and drop pieces which means you can play jenga. There is also /jenga with things like /jenga turn next and last and /jenga start, but they are heavily in beta.

# Config
In the jenga button in the options menu you can control what blocks the tower uses. The turn enforcement is still in very early beta so it might not be done yet. 

# Controls
Right click to start dragging, right click again to stop dragging. Scrolling while drag rotates the piece 90 degrees. If you hold ctrl (rebindable) while scrolling, it will change the distance of the piece from you.
